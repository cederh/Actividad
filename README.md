# Portafolio Profesional - Carlos Romero

Portafolio web desarrollado como proyecto académico. Sitio estático de 4 páginas construido con HTML5 semántico y CSS3 responsivo, sin frameworks ni JavaScript externo.

## Páginas

| Archivo          | Descripción                                        |
| ---------------- | -------------------------------------------------- |
| `index.html`     | Inicio — presentación e introducción al portafolio |
| `acerca.html`    | Perfil profesional, habilidades y experiencia      |
| `proyectos.html` | Historial de proyectos y sistemas en tabla HTML    |
| `contacto.html`  | Formulario de contacto con validaciones HTML5      |

## Tecnologías

- HTML5 semántico (`<header>`, `<main>`, `<aside>`, `<section>`, `<footer>`)
- CSS3 externo — sin estilos en línea
- Flexbox + Media Queries (breakpoints: 576px tablet / 768px desktop)
- Diseño responsivo Mobile First
- Content Security Policy (CSP) via meta tag
